01

输入输出

W3Schools ↗

AIO 判题是拿你程序的输出，跟标准答案逐字比对的。格式差一个字都算错，所以这一节比其他语法都重要。

# 读一行、当字符串处理
name = input()

# 读一个整数（input() 拿到的永远是字符串，要自己转类型）
n = int(input())

# .strip() 去掉首尾多余的空格和换行，养成习惯每次读入都加上
n = int(input().strip())

# 一行里有多个数字，用空格隔开，比如 "3 5 8"
a, b, c = map(int, input().split())

# 输出
print(a + b + c)

1.1一行输入多个数

如果输入是 1 2 3 4，四个数都在同一行，就先用 split() 按空格拆开，再用 map(int, ...) 把每一项转成整数：

# 输入：1 2 3 4
numbers = list(map(int, input().split()))

print(numbers)       # [1, 2, 3, 4]
print(sum(numbers))  # 10

1.2多行输入，每行一个数

如果输入的 1、2、3、4 各占一行，就要调用四次 input()。可以用循环把它们依次加入列表：

# 输入：
# 1
# 2
# 3
# 4
numbers = []
for _ in range(4):
    numbers.append(int(input().strip()))

print(numbers)       # [1, 2, 3, 4]
print(sum(numbers))  # 10
易错

忘记 int() 转换，会把 "3" 当成字符串直接跟别的字符串拼在一起，而不是数字相加。

有些题目输入不止一行——比如先给一个 n，接下来 n 行每行一个数字，这时候要用循环，一行一行读：

# 第一行是 n，接下来 n 行，每行一个整数
n = int(input().strip())
total = 0
for i in range(n):
    total += int(input().strip())

print(total)
易错

看到"接下来若干行"先数清楚要读几行——是 n 行，还是题目另外给了行数，读多读少都会导致后面全错位。

变量与类型

W3Schools ↗

Python 不用先声明类型，赋值的时候类型就定了。竞赛题里主要用这四种。

age = 14          # int，整数
score = 92.5      # float，小数
name = "Aaron"    # str，字符串
passed = True     # bool，True / False（首字母大写）

type(age)         # 想不确定的时候，直接打印看类型
03

运算符

W3Schools ↗

除法这两个最容易搞混，竞赛题里几乎每题都会用到其中一个。

7 / 2    # 3.5   —— 普通除法，结果永远是小数
7 // 2   # 3     —— 整除，只要商的整数部分
7 % 2    # 1     —— 取余数
2 ** 10  # 1024  —— 乘方

3 == 3   # True  —— 判断相等用两个等号
3 != 4   # True  —— 不等于
a > 3 and b < 10   # 且
a > 3 or b < 10    # 或
易错

判断相等是 ==，写成一个 = 会变成赋值，是完全不同的意思。

04

条件判断

W3Schools ↗

Python 不用花括号分块，靠缩进决定哪些代码属于 if 里面。这是 Python 和你写过的 JS 最不一样的地方。

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
易错

同一层的代码缩进必须完全对齐（通常是 4 个空格），缩进错一格程序直接报错，这也是从 JS 转过来最容易踩的坑——JS 靠 { }，Python 靠空格。

05

循环

W3Schools: for ↗while ↗

竞赛题里 for 用得远比 while 多，主要是配合 range() 循环固定次数，或者遍历一个列表。

# 循环 5 次，i 依次是 0,1,2,3,4
for i in range(5):
    print(i)

# 遍历列表里的每一个元素
for x in [10, 20, 30]:
    print(x)

# while：不知道要循环几次，只知道停止条件
n = 100
count = 0
while n > 1:
    n = n // 2
    count += 1

# break 立刻跳出循环，continue 跳过这一轮剩下的部分
06

列表（list）

W3Schools ↗

相当于 JS 里的数组，几乎每道 AIO 题都要用它存一串数字或字符串。

nums = [3, 7, 1, 9]

nums[0]        # 3   —— 索引从 0 开始
nums[-1]       # 9   —— -1 是最后一个
len(nums)      # 4   —— 长度

nums.append(5) # 在末尾加一个元素 → [3,7,1,9,5]
nums.sort()    # 原地排序 → [1,3,5,7,9]
max(nums)      # 最大值
sum(nums)      # 求和

3 in nums      # True —— 判断某个值在不在列表里

# 一行读入 n 个数，存成列表——这个写法竞赛题里几乎天天用
nums = list(map(int, input().split()))
易错

访问超出范围的下标（比如列表长度是 4，却去取 nums[4]）会直接报错崩溃，这在判题时经常是"运行时错误"的原因。

07

map()

W3Schools ↗

前面几节里 map(int, input().split()) 已经出现好几次了——这节把它讲透。map(函数, 列表) 的意思是"把这个函数依次套用到列表的每一个元素上"，不用自己写循环。

# split() 把一行按空格拆开，得到的是字符串列表
"3 7 1".split()          # ['3', '7', '1']  —— 注意还是字符串，不是数字

# map(int, ...) 把 int() 套用到每一个元素上，逐个转成整数
map(int, ["3", "7", "1"])   # 一个 map 对象，还看不到里面的值

# 想看到结果 / 想用下标访问，必须用 list() 包一层
list(map(int, ["3", "7", "1"]))   # [3, 7, 1]

# 所以竞赛题里最常见的写法就是这两个连在一起用：
nums = list(map(int, input().split()))
易错

map() 自己返回的是一个"还没算"的 map 对象，不是列表，不能直接用 nums[0] 这样取下标，也不能直接 print() 看到内容——必须先 list(map(...)) 转成列表才能这样用。

反过来，输出一串数字、要求用空格隔开的时候，map() 配合 str 也是标准写法——因为 print() 要求给它字符串，不能直接把一列整数拼起来：

nums = [3, 7, 1]

# 想输出 "3 7 1"，先把每个数字变成字符串，再用空格拼起来
print(" ".join(map(str, nums)))    # 3 7 1

# 更简单的等价写法：print() 自带按空格分隔多个参数的功能
print(*nums)                        # 3 7 1，效果一样，AIO 题目输出一行数字时最常用
易错

" ".join(nums)（漏了 map(str, ...)）会直接报错，因为 join() 只能拼字符串，nums 里存的是整数——这跟"读入忘了 int()"是同一类问题反过来的版本。

08

字典（哈希表）

W3Schools ↗

字典（dict）就是 Python 里的哈希表——存"键 → 值"的对应关系，通过键几乎瞬间就能查到值，不用像列表那样一个个找。AIO 题目里最常见的用法是计数：统计一串数字/字符里每个值各出现了几次。

# 创建一个空字典，往里面存 键:值
d = {}
d["apple"] = 3
d["pear"] = 5

d["apple"]        # 3   —— 用键直接查值，接近瞬间完成
"apple" in d       # True —— 判断某个键在不在字典里
len(d)             # 2   —— 有几个键

最常用的套路——遍历一个列表，用字典给每个值计数：

nums = [3, 7, 3, 1, 7, 3]
count = {}

for x in nums:
    if x in count:
        count[x] += 1
    else:
        count[x] = 1

# count 现在是 {3: 3, 7: 2, 1: 1}

# 更短的等价写法，用 .get(键, 找不到时的默认值)：
count2 = {}
for x in nums:
    count2[x] = count2.get(x, 0) + 1
易错

直接用 count[x] += 1 而没先判断 x 在不在字典里，如果 x 是第一次出现会报 KeyError（因为字典里还没有这个键，没法对它"+1"）。这是"访问不存在的键"版本的越界错误，跟列表访问超出下标是同一类坑。

遍历字典，同时拿到键和值——找"出现次数最多的元素"这类题目会用到：

for key, value in count.items():
    print(key, "出现了", value, "次")

# 找出现次数最多的元素，两种常用写法：
max(count, key=count.get)     # 3 —— 出现最多的那个键

函数

W3Schools ↗

把重复用到的逻辑包起来，AIO 题目一般不强制要求写函数，但拆出来更容易自己检查对不对。

def is_even(x):
    return x % 2 == 0

def add(a, b):

print(is_even(6))     # True

10

字符串

W3Schools ↗

AIO 有不少题的输入是一串字母——方向指令、DNA 序列、单词。字符串可以看成"一列字符"，所以列表那一套（下标、遍历、排序）大部分都能直接用，只是有几处不一样，下面单独标出来。

10.1拼接与拆分

拼数字和文字一起输出时最常用 f-string，比一堆 + 号拼接清楚很多。

name = "Aaron"
score = 92

print(f"{name} 得了 {score} 分")   # Aaron 得了 92 分

"3,7,1".split(",")    # ['3', '7', '1']
"-".join(["a","b","c"])   # 'a-b-c'
len("hello")           # 5

10.2下标与切片

下标跟列表完全一样。切片 s[开始:结束] 取出一段，包含开始、不包含结束。

s = "hello"

s[0]        # 'h'    —— 第一个字符
s[-1]       # 'o'    —— 最后一个字符
s[1:4]      # 'ell'  —— 下标 1、2、3，不含 4
s[:3]       # 'hel'  —— 省略开始 = 从头取
s[2:]       # 'llo'  —— 省略结束 = 取到末尾
s[::-1]     # 'olleh' —— 倒过来，判断回文最常用

s == s[::-1]    # False —— "hello" 不是回文；"level" 就是 True
易错

下标越界会报错（s[10] → IndexError），但切片越界不会——s[1:100] 安安静静返回 'ello'。所以切片写错了程序不会崩，只会悄悄给出错的答案，更难发现。

10.3遍历字符串

三种写法，按"需要知道什么"来选：只要字符本身、只要位置、两个都要。

# ① 只关心字符本身：直接 for ch in s
word = "education"
vowels = 0
for ch in word:
    if ch in "aeiou":        # in 也能判断"这个字符在不在一串字符里"
        vowels += 1
print(vowels)                # 5

# ② 需要比较前后相邻的字符：用下标 i
s = "aabccc"
same = 0
for i in range(len(s) - 1):  # 注意是 len(s) - 1，否则 s[i+1] 越界
    if s[i] == s[i + 1]:
        same += 1
print(same)                  # 3 —— aa、cc、cc

# ③ 位置和字符都要：enumerate()
for i, ch in enumerate("abc"):
    print(i, ch)             # 0 a / 1 b / 2 c

遍历时经常要"挑出一部分字符，拼成新字符串"——从空字符串开始，一个个往上加：

s = "a1b2c3"
digits = ""
for ch in s:
    if ch.isdigit():
        digits += ch
print(digits)                # 123

10.4字符串不能原地修改

这是字符串和列表最大的不同：列表可以 nums[0] = 5 直接改，字符串不行。想改某个位置的字符，要先转成列表，改完再拼回来。

s = "hello"
s[0] = "j"               # ✗ 报错 TypeError：字符串不能改

chars = list(s)          # ['h', 'e', 'l', 'l', 'o']
chars[0] = "j"
s = "".join(chars)       # 'jello'

10.5排序

字符串没有 .sort()（因为不能原地修改），要用 sorted()——它返回的是一个字符列表，想要字符串还得 "".join() 拼回去。

sorted("banana")                        # ['a', 'a', 'a', 'b', 'n', 'n'] —— 列表！
"".join(sorted("banana"))               # 'aaabnn'
"".join(sorted("banana", reverse=True)) # 'nnbaaa' —— 从大到小

# 经典用法：判断两个词是不是"字母相同、顺序不同"（变位词）
sorted("listen") == sorted("silent")    # True

给一列单词排序时，默认是字典序——像查字典一样，从第一个字母开始逐个比。想按别的规则排，用 key= 告诉它"拿什么来比"：

"apple" < "banana"       # True —— 字符串也能直接比大小，比的就是字典序

words = ["banana", "Cherry", "apple"]
sorted(words)                 # ['Cherry', 'apple', 'banana'] —— 大写字母排在所有小写前面！
sorted(words, key=str.lower)  # ['apple', 'banana', 'Cherry'] —— 忽略大小写

sorted(["pear", "fig", "apple"], key=len)   # ['fig', 'pear', 'apple'] —— 按长度
易错

数字如果还是字符串，排序结果会是错的：sorted(["10", "9", "100"]) 得到 ['10', '100', '9']，因为按字典序 "1" 比 "9" 小。读入后先 map(int, ...) 转成整数再排，才是 [9, 10, 100]。

10.6常用方法速查

这些不用背，知道"有这么个东西"，要用时回来查。注意它们都返回新字符串，原来的 s 不变，要用结果就得赋值。

"hello".count("l")        # 2      —— 出现了几次
"hello".find("ll")        # 2      —— 第一次出现的下标
"hello".find("z")         # -1     —— 找不到返回 -1（不报错）
"hello".replace("l", "L") # 'heLLo' —— 全部替换
"hello".startswith("he")  # True

"Hello".upper()           # 'HELLO'
"Hello".lower()           # 'hello' —— 题目说"不区分大小写"时先统一转小写

"123".isdigit()           # True  —— 全是数字吗
"abc".isalpha()           # True  —— 全是字母吗
"a1".isalpha()            # False

10.7字符 ↔ 数字：ord() 和 chr()

每个字符在电脑里都有一个编号。ord() 查编号，chr() 反过来。竞赛里最常见的用途是"字母是第几个"和"字母往后移几位"。

ord("a")              # 97
ord("A")              # 65  —— 大写和小写编号不同
chr(98)               # 'b'

# 字母是字母表里第几个（从 0 开始）：a→0, b→1, c→2 …
ord("c") - ord("a")   # 2

# 字母往后移 3 位，超过 z 绕回 a（凯撒密码）
ch = "x"
chr((ord(ch) - ord("a") + 3) % 26 + ord("a"))   # 'a'
连起来

统计"每个字母出现几次"，用第 8 节的字典计数套路，把 for x in nums 换成 for ch in s 就行——下一节课的例题就是这么做的。

常见坑清单

这些是判题时最常出现"明明思路对却拿不到分"的原因，出问题先查这里。

✗ 容易写错input() 直接拿去加法运算
✓ 应该这样int(input()) 先转成数字
✗ 容易写错缩进用了 3 个空格，下一行用了 4 个
✓ 应该这样同一层永远保持相同的缩进数量
✗ 容易写错用 / 算下标或计数
✓ 应该这样需要整数结果时用 //
✗ 容易写错循环里用 nums[i+1] 没检查越界
✓ 应该这样先确认 i+1 < len(nums)
✗ 容易写错s[0] = "j" 或 s.sort() 直接改字符串
✓ 应该这样先 list(s) 改完再 "".join()；排序用 sorted(s)
✗ 容易写错数字还是字符串就排序，"10" 排在 "9" 前面
✓ 应该这样先 map(int, ...) 转成整数再排

完整例题：从读题到写完

把上面这些语法串起来看一遍完整流程——这就是几乎所有 AIO 简单题的固定套路。

题目：第一行输入一个整数 n，第二行输入 n 个用空格隔开的整数，输出其中的最大值和它们的总和，用空格隔开。
1
读懂输入格式 —— 两行：第一行是个数 n，第二行是 n 个数。
2
想清楚要算什么 —— 最大值用 max()，总和用 sum()，都是列表现成的函数。
3
想清楚输出格式 —— 两个数中间一个空格，不能多逗号也不能少空格。
n = int(input())
nums = list(map(int, input().split()))

biggest = max(nums)
total = sum(nums)

print(biggest, total)
